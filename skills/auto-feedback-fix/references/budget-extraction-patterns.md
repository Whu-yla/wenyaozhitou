# 预算提取正则模式库

## 南网格式（HTML 表格）
```
最高投标限价（万元）</span></p></td><td style="..."><p>55.79</p></td>
→ r'最高(?:投标)?限价[^<]*?</td>\s*<td[^>]*>\s*(\d+\.?\d*)'
```

## 南网格式（纯文本）
```
最高投标限价（万元） 55.79
→ r'最高(?:投标)?限价[（(][^)）]*万元[）)]\s*(\d+\.?\d*)'
```

## 通用格式
```
最高投标限价：55.79万元
→ r'最高投标限价[：:]\s*(\d+\.?\d*)\s*万'

最高限价：55.79万
→ r'最高限价[：:]\s*(\d+\.?\d*)\s*万'

预算金额：169万
→ r'预算金额[：:]\s*(\d+\.?\d*)\s*万'
```

## ⚠️ 误抓陷阱 — 必须过滤
| 误抓值 | 来源 | 过滤方法 |
|:--|:--|:--|
| `0.67` | `border-width:0.67px` | 过滤 < 1.0 |
| `10.5` | `font-size:10.5pt` | 过滤值出现在 CSS 上下文中的 |
| `1.0` | 各种 CSS 单位 | 过滤 < 2.0 |
| `2025`/`2026` | 年份 | 过滤 2000-2100 范围 |

## 最佳实践
1. **先 strip html 再 regex**：`re.sub(r'<[^>]+>', ' ', html)`
2. **找到 header，取之后最近的数字**：`re.findall(r'(\d+\.\d+)', tail)`
3. **过滤非金额值**：`if 1.0 < float(val) < 100000`
