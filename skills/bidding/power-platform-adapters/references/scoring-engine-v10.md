# 评分引擎 V10 修复记录

## 问题
中广核主页提取的数字化项目（如"信息**安全**设备采购"、"**数字化**业务服务"）被评分引擎全部过滤，0条入库。

## 根因

### 1. DIGITAL_GATE（硬门槛）太窄
"信息安全"、"网络安全"、"等保测评" 等安防类关键词不在 DIGITAL_GATE 中 → 直接返回 None。

### 2. 无 CORE/STRONG 关键词命中导致分数不足
即使通过门槛（如"数字化"），若没有 CORE_KEYWORDS（+35）或 STRONG_KEYWORDS（+18），仅靠 CUSTOMER_KEYWORDS（+12）→ 总分12 → 不达55分底线 → None。

## 修复内容 (V10)

### DIGITAL_GATE 新增关键词
```python
# v10: 信息安全 & 等保
"信息安全", "网络安全", "等保测评", "安全防护", "安全评估",
"态势感知", "工控安全", "数据安全",
```

### STRONG_KEYWORDS 新增关键词
```python
# v10: 信息安全 & 数字化服务
"信息安全", "网络安全", "数字化", "智能化",
"信号采集", "技术服务", "安全防护",
```

### 门槛基础分（核心修复）
通过 DIGITAL_GATE 的项目自动获得 **25 分基础分**，代表 IT/数字化项目的固有价值：
```python
# 通过数字门槛即给基础分（代表IT/数字化项目的固有价值）
raw_score += 25
tags.append("★digital_gate")
```

### 评分公式示例
"中广核新能源集团统筹共享数字化业务服务采购项目"：
- 25 (gate bonus) + 18 (STRONG: 数字化) + 12 (CUSTOMER: 中广核) = 55 ✓

## 已确认有效
修复后中广核 2 条入库（75分 + 55分）。
