# V1.33 UX Enhancement Patterns — Complete Reference (2026-06-26)

## Empty State Design
- No-results must show guidance text + "清除所有筛选" button — dead-end pages lose users
- `smartEmptyMsg(query, dataCount)` handles: no data, starred-empty, no-match
- Empty state `td[colspan]` uses `.empty-msg` class with centered layout
- Clear-filter button calls `resetF()` — one-click return to full dataset

## URL State Sync
- `syncUrl()` called after every `doFilter()` — uses `history.replaceState`
- `restoreUrl()` called during `init()` — reads `URLSearchParams`
- Parameters: `q` (search), `cat`, `prov`, `score`, `budget`, `from`, `to`, `tab`, `sort`, `dir`
- Enables sharing filtered views via URL copy — no screenshots needed

## IME-Safe Search
- `compositionstart`/`compositionend` flags track Chinese input state
- Enter key only triggers search when `!composing`
- Search button bound with `addEventListener('click', doFilter)` — more reliable than `onclick` attribute
- Desktop + mobile both use button-confirm model

## Row Density Toggle
- `≡` button in header toggles `body.dense` class
- Desktop: shrinks row height to 32px, font to 11px
- **Mobile: dense rules MUST be overridden in `@media(max-width:768px)`** — cards need 18px padding, 13px font
- Preference persisted in `localStorage('density')`

## Score Legend Tooltip
- `ⓘ` icon on relevance column header → `showScoreLegend(event)`
- Popup shows green(85+)/yellow(60-84)/gray(<60) bands with descriptions
- `position:fixed` with viewport boundary clamping, light theme adapts

## Keyboard Shortcuts
- `/` → focus search (skip if in input/select/textarea)
- `Esc` → close chat panel > close kebab > reset filters
- `Ctrl+Enter` → `smartExport()`
- `Ctrl+←/→` → switch bid/win tabs
- `Ctrl+S` → star tab

## Desktop Hover Preview
- Long titles (>60 chars) show popup on 600ms hover delay
- `position:fixed` below the title cell, max 500px width
- Uses `pointer-events:none` to not block clicks

## Dense Mode Mobile Exemption (CRITICAL PITFALL)
`body.dense` global rules will crush mobile card grid layout. Must override inside `@media(max-width:768px)`:
```css
body.dense tbody td{padding:0!important;font-size:13px!important}
body.dense thead th{display:none!important}
body.dense tbody tr{height:auto!important;padding:18px 16px!important}
body.dense .star{font-size:16px!important}
body.dense .score-bar{display:none!important}
body.dense .tag-sm{font-size:12px!important}
body.dense .link-btn{font-size:13px!important}
```
Do NOT use `display:none` to hide dense mode entirely — it would lose the user's density preference from localStorage.

## Desktop-Mobile Separation Post-Filter-Bar-Restructuring
When filter bar was restructured (export/reset moved as filter-bar siblings for desktop right-alignment),
mobile broke because `filter-bar{display:block}` stacked them vertically. Fix: hide extras on mobile.
```css
@media(max-width:768px){
  .filter-bar > span:not(.search-icon),
  .filter-bar > .pg-btns{display:none!important}
  .filter-bar > .btn{display:none!important}
  .filter-bar > .btn[onclick*="smartExport"]{display:inline-flex!important}
}
```

## Polish Script Precision Rule
`html.replace('overflow:hidden', 'overflow:visible')` hits BOTH desktop and mobile filter-scroll-wrapper.
Must use complete context string to target only desktop:
`html.replace('.filter-scroll-wrapper{flex:1;min-width:0;overflow:hidden}', '.filter-scroll-wrapper{flex:1;min-width:0;overflow:visible}')`
