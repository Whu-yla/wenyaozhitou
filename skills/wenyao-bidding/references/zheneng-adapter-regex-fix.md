# 浙能适配器 — 标题截断+日期提取修复 (V1.24)

## 时间
2026-06-26 00:30

## 触发
用户报告唯一 NEW 项目 id=389：
- 标题显示为「招标公告浙江浙能浙江」→ 实际应为「浙江浙能中煤舟山煤电有限责任公司扫频磁电除垢仪采购招标公告」
- 日期显示为「2026-06-26」→ URL 含 06-25，公告落款 06-24

## 根因 1：标题正则 `\s*浙能` 停止条件误匹配司名

### 原始代码 (adapter_zheneng.py:67)
```python
m = re.search(r'(?:招标公告|采购公告|中标候选人公示|中标结果公告|变更公告)\s*(.+?)(?:\s*招标公告|\s*\n|\s*浙能|\s*ZJTY)', text)
```

### 问题
停止条件 `\s*浙能` 在 `.+?` 非贪婪模式下首先匹配到公司名中的「浙能」：
- 输入：`...招标公告浙江浙能中煤舟山煤电有限责任公司扫频磁电除垢仪采购招标公告...`
- `.+?` 捕获：`浙江`（最小匹配）
- 停止：`浙能`（在「浙江**浙能**中煤…」处触发）
- 结果标题：`招标公告` + `浙江` = **「招标公告浙江」**（被截断）

m.group(0) 包含停止条件的「浙能」→ 最终拼接为「招标公告浙江浙能浙江」。

### 修复
```python
# 方式1：匹配完整公司名+公告类型模式（不以关键词为停止条件）
m = re.search(r'((?:浙江|浙能|国家能源|华能|华电|大唐|国电|中电投|南方电网|国网)\S{0,80}(?:招标公告|采购公告|中标候选人公示|中标结果公告))', text)
```

停止条件改为「已具备招标条件」、「\n\n」等自然段落边界，而非公司的常见名称片段。

## 根因 2：日期正则匹配到平台当天日期

### 原始代码 (adapter_zheneng.py:94)
```python
m = re.search(r'(\d{4})年(\d{1,2})月(\d{1,2})日', text[:2000])
```

### 问题
在全文前 2000 字符中扫描中文日期格式。平台页面模板可能在头部显示当天日期（如 `2026年6月26日`），而非公告的实际落款日期（`2026年6月24日`）。正则无上下文约束 → 命中第一个日期 → 结果是平台显示日期而非公告日期。

### 修复
```python
# 优先匹配公告落款：在"招标人"/"招标代理机构"附近找日期
m_doc = re.search(r'(?:招标人|招标代理机构|采购人|采购代理机构).{0,300}?(\d{4})年(\d{1,2})月(\d{1,2})日', text[:3000])
if m_doc:
    date = f"{m_doc.group(1)}-{int(m_doc.group(2)):02d}-{int(m_doc.group(3)):02d}"
# 兜底：第一个中文日期
# 最后兜底：URL 中的日期 (/2026-06-25/)
```

## 设计原则

1. **正则停止条件不能匹配公司名称片段** — `浙能`、`华能`、`国网` 等常见于公司名中
2. **日期提取必须有上下文约束** — 不能只是「全文找到第一个日期」。公告落款日期通常靠近「招标人」「招标代理机构」等特征段
3. **URL 日期作为最后兜底** — URL 中的日期是列表页的发布日期，通常比公告正文中的落款日期晚 1-2 天
4. **修复脏数据必须回填** — 改完适配器后，已入库的错误记录需要 `UPDATE` 修复
