# 评分引擎 v7 (100分制)

## 设计原则

1. **DIGITAL_GATE 硬门槛**: 标题+正文必须命中至少1个数字/智慧关键词，否则直接排除
2. **泛词陷阱**: "工程"、"项目"、"建设"、"监理"、"项目管理"、"工程管理" 绝不能出现在正向关键词中——它们出现在几乎所有公告标题里
3. **公司名匹配**: "XX工程项目管理有限公司"会误匹配"项目管理"，必须通过DIGITAL_GATE提前拦截
4. **林业/储备林/教育/教学/医疗**: 硬排除，第一时间踢出
5. **EPC/施工**: 分包/劳务/土建/混凝土/变电工程 等施工词汇无数字关键词伴随 → 排除

## 评分公式

```
final_score = min(round(raw_score × geo_weight), 100)

where:
  raw_score = Σ(CORE×35) + Σ(STRONG×18) + Σ(CUSTOMER×12) + Σ(GENERAL×8)
  GEO_KEYWORDS only activate if (CORE or STRONG matched) AND raw_score ≥ 35
  geo_weight ∈ [0.5, 1.0] based on province
  final ≥ 55 → 入库
  final ≥ 80 → 企微推送
```
