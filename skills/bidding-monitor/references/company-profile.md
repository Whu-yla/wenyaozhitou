# 数智科技公司业务画像

## 主体
- **全称**：中国电力工程顾问集团中南电力设计院有限公司数智科技公司
- **地址**：湖北武汉武昌区
- **本质**：数字技术公司（不是EPC施工公司），30+发明专利，90+软著

## 核心产品
- 智孪万维：数字孪生/低代码平台
- 智电万通：电力AI中台/训推一体
- 智海万析：大数据/知识图谱
- 天空地海深一体化：IoT感知平台
- 文鳐系列：智能巡检、安全管理
- 玄武系列：SSK/SRK/SPK/SIK 数字方案
- 可信数据空间：数据安全共享交换

## 行业方案（会投标的）
- 电厂：智慧工地/电厂/安全管控、三维数字化移交
- 电网：输变电数字化设计、线路仿真监测、变电站验收
- 新能源：风电/光伏智慧基建管控运维、集控中心
- 其他：智能楼宇/园区、矿山智能管控、信创改造

## 竞品分类
1. 电力设计院同业（电建/能建/省级电力设计院）
2. 五大发电集团（华能/华电/大唐/国电投/国家能源）
3. 电网公司（国网/南网）
4. 电力IT企业（许继/南瑞/四方/朗新/远光/恒华/金智）
5. 互联网大厂（华为/阿里/腾讯 — 数字孪生/AI领域）
