# 企微推送格式规范 v3

## 推送决策树

```
今日新增 >= 1 条?
├── YES → 发送完整日报卡片 (统计+TOP5+链接)
└── NO  → 静默计数器 += 1
           ├── 计数器 < 3 → 不发
           └── 计数器 >= 3 → 发送心跳
```

## 企微 Markdown 限制

- 不支持表格（用emoji排版代替）
- 不支持颜色（用 `🟢🟡⚪🔴🟠🔵` emoji区分级别）
- 不支持图片（用链接指向报告）
- 单条消息限制4096字符（过长自动触发精简版fallback）
- Markdown支持：`##`标题 `>`引用 `**`加粗 `` ` ``代码
- `<font color="comment">` 灰色小字用于尾部署名
