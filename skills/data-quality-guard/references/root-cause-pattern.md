# 根因分析模式

> 2026-06-25 用户铁律：「修复BUG都是结果，要深层次的分析原因，以后不要再犯！」

## 两种修复模式

| ❌ 擦地（症状修复） | ✅ 根治（源头拦截） |
|:--|:--|
| 发现垃圾→DELETE删掉 | 追溯管道→堵源头→加防护层 |
| 发现锅炉100分→排除词加一个 | 分析为什么DIGITAL_GATE没拦住→收紧GATE+加排除层 |
| 同样问题反复出现 | 写skill文档化根因→下次自查先看skill |

## 每次发现数据质量问题的SOP

1. **定位**：脏数据id→查content_summary→确认是哪个爬虫/适配器产出的
2. **追溯**：读爬虫源码→找为什么没拦截
3. **堵源头**：在最早的拦截点加判断（L1>L2>L3）
4. **回填**：UPDATE 修复已有脏数据
5. **文档**：写skill/changelog
6. **验证**：浏览器渲染+curl检查
